Executive Summary & Business Objectives

The eBay ACES Platform centralizes customer support across multiple eBay seller accounts (Main, Marine, Tech, Ship, Tools, Trade). Agents manage all buyer messages, replies, and assignments from a single WhatsApp‑style interface, eliminating manual account switching. Built on FastAPI, React, PostgreSQL, Redis & Celery, the system reduces first response time by ≥40%, enforces accountability via assignment, and provides real‑time analytics.

Business Rules

  • BR-01: One conversation per (eBay account, buyer username).
  • BR-03: New customer message on Resolved conversation → auto Reopened.
  • BR-05: Agent sees conversation iff assigned to them OR belongs to assigned category (unassigned).
  • BR-07: Low‑confidence AI categorization (Phase 2) routes to Unassigned Queue (Manager/Admin only).
  • BR-12: 24h SLA clock pauses when status = Pending; resumes on customer reply.
  • BR-15: All stored timestamps in UTC; UI converts to user local time.
  • BR-13: Sent messages are immutable; no edit or delete.
  • BR-16 (Universal Assignment): Any authenticated user (Admin, Manager, Agent) can reassign any conversation to any other active user. The system records the assignment and sends an in‑app notification to the new assignee.
  • BR-17 (Manual Sync): Only Admin and Operation Manager roles have access to the "Sync Now" button. Sync operation fetches new messages from eBay for all connected accounts. No automatic periodic sync is performed.

Message flow (manual): Admin/Manager triggers sync → Celery task → fetch from eBay → deduplication → conversation upsert → UI refresh.
Reply flow: Agent → API → local PENDING record → Celery task → eBay → status update & audit.
Universal assignment flow: Any user selects conversation → chooses target user (any role) → API updates assigned_user_id → Audit log → In‑app notification to new assignee.

Workflow Specifications & UI Mockups

1. Manual Sync: Admin/Manager clicks “Sync Now” button → Background Celery task fetches latest messages from eBay for all accounts → New messages appear in conversation list. No automatic polling.
2. Reply Sending: Compose → persist PENDING → Celery call eBay API → update status → audit.
3. Universal Assignment: Any user (including Agent) opens a conversation → clicks “Assign to” → selects any active user (Admin, Manager, or another Agent) → system updates assigned_user_id → audit log entry → pushes in‑app notification to assignee: “Conversation from [buyer] assigned to you by [assigner_name]”.

Security & Audit Compliance

Security: TLS 1.2+, Argon2id password hashing, AES-256-GCM for eBay tokens, JWT with short TTL, rate limiting, CSRF protection, input validation via Pydantic.

Audit Logging: Every state change (assignment, category, status, reply, login) logged with actor, timestamp, IP, previous/new values. Immutable, retention ≥24 months. Admins can filter & export. Assignment events capture source user, target assignee, conversation ID.
