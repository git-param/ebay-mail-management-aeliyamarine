Executive Summary & Business Objectives

The eBay Omni-Desk Platform centralizes customer support across multiple eBay seller accounts (Main, Marine, Tech, Ship, Tools, Trade). Agents manage all buyer messages, replies, and assignments from a single WhatsApp‑style interface, eliminating manual account switching. Built on FastAPI, React, PostgreSQL, Redis & Celery, the system reduces first response time by ≥40%, enforces accountability via assignment, and provides real‑time analytics.

Business Rules

  • BR-01: One conversation per (eBay account, buyer username).
  • BR-03: New customer message on Resolved conversation → auto Reopened.
  • BR-05: Agent sees conversation iff assigned to them OR belongs to assigned category (unassigned).
  • BR-07: Low‑confidence AI categorization (Phase 2) routes to Unassigned Queue (Manager/Admin only).
  • BR-12: 24h SLA clock pauses when status = Pending; resumes on customer reply.
  • BR-15: All stored timestamps in UTC; UI converts to user local time.
  • BR-13: Sent messages are immutable; no edit or delete.

1. Inbound Sync: Scheduler (2‑5 min) → fetch messages → deduplicate → create/append conversation → notify.
2. Reply Sending: Compose → persist PENDING → Celery call eBay API → update status → audit.

Security & Audit Compliance

Security: TLS 1.2+, Argon2id password hashing, AES-256-GCM for eBay tokens, JWT with short TTL, rate limiting, CSRF protection, input validation via Pydantic.

Audit Logging: Every state change (assignment, category, status, reply, login) logged with actor, timestamp, IP, previous/new values. Immutable, retention ≥24 months. Admins can filter & export.
